# Hardware

Altium Designer project for the custom actuator board: STM32G431 + DRV8316 (integrated current sense) + CAN transceiver + MT6701 encoder.

- Commit: `.PrjPcb`, `.SchDoc`, `.PcbDoc`, libraries, `.OutJob`.
- Ignored: Altium `History/`, previews, and auto-generated `Project Outputs`.
- `fab/`: final Gerbers, drill files, BOM, and pick-and-place for each board revision you actually order (e.g. `fab/rev-a/`).
- Add a PDF of the schematic for each revision so people without Altium can read it.
