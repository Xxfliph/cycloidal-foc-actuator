# Mechanical

SolidWorks parts and assemblies for the 10:1 cycloidal drive.

- Native `.SLDPRT` / `.SLDASM` files live here.
- `export/`: STEP and STL exports of finalized parts. GitHub previews STLs in the browser, and STEP opens in any CAD tool.
- Record print settings (material, layer height, infill, orientation) for each printed part in this file or in `docs/log.md`.
